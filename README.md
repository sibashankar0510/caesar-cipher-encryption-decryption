# Caesar Cipher Encryption and Decryption

## About the Project
This is my second project as part of my Decode Labs internship. It is a simple Python program that demonstrates the basic working of Caesar Cipher encryption and decryption.

The program uses a shift key to move letters forward in the alphabet to encrypt a message and backward to decrypt it.

## Features
- Encrypts messages using a shift key.
- Decrypts messages to recover the original text.
- Supports uppercase and lowercase letters.
- Preserves spaces, numbers, and special characters.
- Takes input directly from the user.

## Technologies Used
- Python 3

## Concepts Learned
- Python functions
- For loops and conditional statements
- `ord()` and `chr()` functions
- Modulo operator (`%`)
- Basic cryptography concepts

## Example

**Input:**
- Message: `Hello World`
- Shift Key: `3`

**Output:**
- Encrypted Message: `Khoor Zruog`
- Decrypted Message: `Hello World`

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python "Basic Encryption & decryption .py"
```

5. Enter your message and shift key when prompted.
